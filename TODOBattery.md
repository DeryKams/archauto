## Обновлённые параметры

| Элемент           | Размер / поведение                     |
| ----------------- | -------------------------------------- |
| Батарея в Waybar  | \~72 × 24 px                           |
| Заполнение        | Непрерывное, от 0 до 100%              |
| Процент           | По центру батареи, поверх шкалы        |
| Выпадающая панель | \~260 px шириной                       |
| Выбор режима      | Вертикальный список из трёх пунктов    |
| Активный режим    | Голубая рамка и галочка                |
| Потребление       | Одно значение в Вт                     |
| Ёмкость           | `Осталось / Всего`, одна строка в Вт·ч |
| Остаток времени   | Одна строка, только при наличии данных |

Для ёмкости используются `Energy / EnergyFull` из UPower. Это текущая оставшаяся энергия и максимальная ёмкость при сегодняшнем состоянии аккумулятора, а не заводская ёмкость. `EnergyRate` соответствует мощности заряда или разряда в ваттах.&#x20;

## Что меняется в реализации

Структура файлов остаётся небольшой:

```
desktop/.config/
├── waybar/
│   ├── config.jsonc              # Заменить power-profiles-daemon
│   ├── style.css                 # Компактный индикатор батареи
│   └── scripts/
│       └── battery-status.py    # Данные и заполнение батареи
└── power-widget/
    ├── panel.py                 # Выпадающая панель и выбор профилей
    └── style.css                # Компактный Liquid Glass
```

Из `config.jsonc` удаляется старый `power-profiles-daemon`, а вместо него подключается `custom/battery`. Из `style.css` удаляются два старых селектора `#power-profiles-daemon`; они заменяются стилями нового индикатора.

Для непрерывной шкалы используем градиент заполнения, а не отдельные символы-сегменты. GTK CSS поддерживает `linear-gradient()`, а пользовательский модуль Waybar — динамические классы, которые можно использовать для изменения уровня заполнения.&#x20;
